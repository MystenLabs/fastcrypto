Module mldsa65 

Source
Expand description

This module contains an implementation of the ML-DSA-65 signature scheme from FIPS 204, on top of the mysten-mldsa-native-rs wrapper around the mldsa-native C library.

The private key is the 32-byte seed from which FIPS 204 derives the full signing key. Signing is hedged (the FIPS 204 default): each signature draws fresh randomness from the operating system, so two signatures over the same msg differ while both verify. The FIPS 204 context string is fixed to empty.

Signatures are therefore neither reproducible nor unique for a given key and msg, so signature bytes must not be used as an identifier or a replay key.

msgs can be signed and the signature can be verified again:

use rand::thread_rng;
let keypair = MLDSA65KeyPair::generate(&mut thread_rng());
let msg: &[u8] = b"Hello, Q world!";
let signature = keypair.sign(msg);
assert!(keypair.public().verify(msg, &signature).is_ok());
