FORS implementation from FIPS-205

Every WOTS+ leaf at the bottom layer of the hypertree (layer=0) has a distinct FORS forest beneath it. So callers must set:

  • xmss height, xmss index & keypair address to that of the WOTS+ key
  • type to FORS_TREE
